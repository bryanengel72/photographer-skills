# Photographer Skills

Landing page for a small library of Claude Skills built for working
photographers. Static single page, no build step.

**Live:** https://photographer-skills.vercel.app

## Skills

- [shoot-day-commander](https://github.com/bryanengel72/shoot-day-commander) —
  runs a corporate headshot day end to end. Available now.
- `lightroom-cull-assistant` — in progress
- `photo-blog-seo-engine` — in progress
- `client-quote-builder` — in progress

## Editing

Everything lives in `index.html` — markup, styles, and content in one file.
Open it in a browser to preview; push to `main` to publish.
